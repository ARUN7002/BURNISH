# Best Practices

Each development session should answer:

- What was planned?
- What was completed?
- What problems occurred?
- How were they solved?
- What was learned?
- What happens next?

Keeping accurate daily records improves project management and simplifies future reviews.

---

# Key Takeaways

- Record progress every development day.
- Document both successes and challenges.
- Keep Git activity synchronized with daily work.
- Maintain a continuous engineering history for Burnish.
