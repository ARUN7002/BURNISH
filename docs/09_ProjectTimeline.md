# Success Criteria

The Burnish project will be considered successful when it can:

- Connect to DataHub.
- Scan enterprise metadata.
- Detect governance issues.
- Generate explainable AI recommendations.
- Allow users to approve or reject recommendations.
- Update metadata in DataHub.
- Maintain a complete audit trail.
- Demonstrate the entire workflow within three minutes.
