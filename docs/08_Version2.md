# Purpose

This document defines the long-term vision of Burnish beyond the hackathon MVP.

The MVP is intentionally focused on solving one governance workflow exceptionally well. Version 2 expands Burnish into a comprehensive AI-powered governance platform capable of supporting enterprise-scale metadata management.

This roadmap ensures that future development remains aligned with the project's vision while preventing unnecessary features from delaying the MVP.

# Planned Features

## AI Governance Assistant

Enhance Burnish with conversational AI capable of answering governance-related questions.

Examples:

- Why is this dataset missing an owner?
- Which datasets have the highest governance risk?
- What changed during the last scan?

---

## Predictive Governance

Use historical metadata to identify datasets that are likely to become governance risks before problems occur.

---

## Governance Quality Score

Assign a governance score to every dataset based on:

- Ownership
- Documentation
- Lineage
- Glossary completeness
- Metadata freshness

Display scores using dashboards and trends.

---

## Policy Learning

Allow Burnish to learn governance rules specific to an organization.

Example:

- Required metadata fields
- Naming standards
- Ownership policies
- Domain-specific rules

---

## Multi-Agent Collaboration

Introduce specialized AI agents working together.

Examples:

- Scanner Agent
- Recommendation Agent
- Documentation Agent
- Compliance Agent
- Audit Agent

Each agent focuses on a specific governance responsibility.

---

## Advanced Analytics Dashboard

Provide enterprise-level insights including:

- Governance trends
- Metadata quality trends
- Department comparisons
- Issue categories
- Resolution statistics

---

## Enterprise Notifications

Integrate Burnish with:

- Microsoft Teams
- Slack
- Email
- Webhooks

Notify users when governance issues require attention.

---

## Workflow Automation

Support scheduled governance scans and automated approval workflows for low-risk changes, while preserving auditability.

---

## Enterprise Security

Future releases may include:

- Role-Based Access Control (RBAC)
- Single Sign-On (SSO)
- Organization management
- Fine-grained permissions
- Audit compliance reporting

---

## External Integrations

Expand beyond DataHub by integrating with platforms such as:

- Snowflake
- BigQuery
- Databricks
- dbt
- Apache Airflow
- Tableau
- Power BI

---

# Long-Term Product Vision

Burnish aims to become an intelligent governance companion that continuously monitors enterprise metadata, assists governance teams with explainable AI, and automates repetitive governance tasks while keeping humans in control of critical decisions.

Rather than replacing governance professionals, Burnish enhances their productivity and helps organizations build greater trust in their data.
